# AthleteHub Demo (public / readable)

This repository is a **readable code sample** of AthleteHub — a baseball & softball stats tracking Flutter app.

It focuses on **UI and client structure** (screens, widgets, navigation, themes, models). It is **not** the full production product.

## Included

- Player shell: Home, Stats, Log game, History, Account
- Dashboard / rank UI, history, flashcard entry, settings screens
- Themes and shared widgets

## Not included (private / production only)

- Cloud Functions (Scout, Zuno, AI analysis)
- In-app purchase / Pro billing
- Data export & PDF report services
- Production Firebase config and secrets
- Internal deploy / ops docs

The complete private codebase lives in a separate private repository.

## Note

This tree is meant for **code review and portfolio reading**. It may not build or run without wiring your own Firebase project and stubbing removed Pro modules.
